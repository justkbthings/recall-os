# Recall OS workspace

Recall OS is a local-first active-recall and spaced-repetition desktop
application owned by **Karabo Goodwill Nkambule**.

The workspace contains:

- `app.py` — the original Streamlit/SQLite prototype;
- `App.tsx` — the original standalone React component prototype; and
- `recall-os/` — the production React, Tailwind CSS, TypeScript, and Electron
  desktop application.

The production application stores study data on the user's device. Databases,
local-storage recovery snapshots, installers, generated release folders, and
private certificate material are intentionally excluded from Git.

See [`recall-os/README.md`](recall-os/README.md) for development, packaging,
signing, and installation details.
